# ITGenius Billing Web

Web-based billing application migration from billingCosolebase.

## Target stack

- Python 3.12+
- Django
- Django REST Framework
- MySQL
- Bootstrap 5
- ReportLab
- openpyxl
- pytest
- Docker / Docker Compose
- Gunicorn

## Modules

- Authentication and role management
- Dashboard
- Customer Master
- Category Master
- Product Master and inventory
- Quotations and PDF generation
- Invoices and PDF generation
- Payments
- Reports
- Company settings
- Audit and application logging

## Status

Migration in progress.
